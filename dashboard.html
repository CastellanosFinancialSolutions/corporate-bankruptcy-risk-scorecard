Nota sobre las variables del modelo. Varios de los 95 ratios financieros de este dataset (entre ellos Current Ratio) vienen pre-normalizados por la fuente (UCI/Kaggle) de una forma no completamente documentada, con rangos muy distintos a los convencionales (ej. Current Ratio aparece entre 0 y 0,02 en vez de 0,5x-3x). El poder discriminante del modelo es igual de valido estadisticamente, pero estas variables no deben leerse con la interpretacion convencional del ratio (no leer 0,01 como "1% de liquidez"). Ver el informe financiero completo para el detalle de esta limitacion y de las variables mas predictivas confirmadas por Information Value y Random Forest.
